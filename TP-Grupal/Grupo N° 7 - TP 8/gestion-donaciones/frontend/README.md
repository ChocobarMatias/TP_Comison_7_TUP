# Frontend - Sistema de Gestión de Donaciones

## Instalación

```bash
npm install
```

## Desarrollo

```bash
npm run dev
```

## Build

```bash
npm run build
```

## Credenciales

- Usuario: `admin`
- Contraseña: `1234`

## Nota

Asegúrate de que el backend esté corriendo en `http://localhost:3001` antes de usar la aplicación.
