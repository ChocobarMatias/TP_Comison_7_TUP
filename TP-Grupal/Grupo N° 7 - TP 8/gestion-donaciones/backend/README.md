# Backend - API Fake con json-server

## Instalación

```bash
npm install
```

## Uso

Para levantar el servidor de API:

```bash
npm run server
```

El servidor estará disponible en: `http://localhost:3001`

## Endpoints

- `GET /api/donantes` - Obtener todos los donantes
- `GET /api/productos` - Obtener todos los productos
- `GET /api/entregas` - Obtener todas las entregas
- `GET /api/donaciones` - Obtener todas las donaciones

Los datos se almacenan en `db.json` y se actualizan automáticamente.
